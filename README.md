# SOFWAH PRISM — Portal

Portal awam (GitHub Pages) untuk **https://prism.sofwah.my**. Ia hanya memaparkan Web App Google Apps Script SOFWAH PRISM dalam iframe skrin penuh + PWA.

- Tiada data, token atau logik HR disimpan di sini. Keselamatan (log masuk PIN, OTP, RBAC) dikuatkuasa di backend Apps Script.
- `index.html` → aplikasi, `war/` → Mod WAR (TV).
- DNS (Exabytes): `CNAME prism → abuqohafah1-stack.github.io`
- Kod sumber: repositori peribadi `sofwah-prism`.
